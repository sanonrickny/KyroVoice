History

Your last 24 hours, then gone.

  • Kept24 hours. Older entries are deleted the moment the window opens.
  • StoredOne file on your Mac, readable only by you.
  • ClearedClear All, any time.
  • CopyGrab any line again without dictating it twice.

Privacy

Nothing is uploaded.

  • AudioHeld while you talk, then dropped. Never written to disk.
  • RecognitionOn the Neural Engine, in process. No account, no telemetry.
  • NetworkUsed once, for the model. After that you can dictate offline.

Install

Clone it and build.

$ git clone https://github.com/sanonrickny/KyroVoice.git
$ cd KyroVoice
$ ./setup_deps.sh   # once
$ make install
  • Hotkey⌘ ⇧ Space, held.
